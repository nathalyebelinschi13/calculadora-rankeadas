# 🎮 Calculadora de Partidas Rankeadas

Este projeto foi desenvolvido como um desafio prático para consolidar conhecimentos básicos em **JavaScript** e lógica de programação.

## 📝 Objetivo
O objetivo é criar uma função que calcule o saldo de vitórias e derrotas de um jogador e determine o seu nível de ranking com base na quantidade de vitórias.

## 🚀 Tecnologias e Conceitos Utilizados
- **Variáveis**: Armazenamento de dados do jogador.
- **Operadores**: Cálculos matemáticos para o saldo.
- **Funções**: Encapsulamento da lógica do desafio.
- **Estruturas de Decisões (if/else)**: Verificação dos intervalos de vitórias para definir o nível (Ferro até Imortal).

## 🏆 Níveis de Ranking
O sistema classifica o herói entre os níveis:
- Ferro, Bronze, Prata, Ouro, Diamante, Lendário e Imortal.
